# 01AI-MathematicsOfAI

This project is based on the Unity Learn unit [The Mathematics of AI](https://learn.unity.com/course/artificial-intelligence-for-beginners/unit/the-mathematics-of-ai?version=6.0), which is part of Unity's [Artificial Intelligence for Beginners](https://learn.unity.com/course/artificial-intelligence-for-beginners?version=6.0) course.

A playable web build can be found here:

[Play the demo on Unity Play](https://play.unity.com/en/games/5ef61a63-50fb-499e-b29b-6c41c6cf341e/01ai-mathematicsofai)

## Scenes

### Scene Select

Click one of the on-screen buttons to select a scene. Press the **R** key at any time to return to this scene.

### Simple AI Follow

Use **WASD** to control the farmer.

In this scene, geometry and trigonometry are used to manually move and rotate game characters. These concepts form the foundation for how game AI agents navigate the world.

### Vision Cone and Chase Distance

Use **WASD** to control your first-person character.

In this scene, the AI agent is given a vision cone and follow distance, demonstrating the basic fundamentals of AI perception.
